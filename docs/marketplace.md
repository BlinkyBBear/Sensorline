## Decisions for the publisher

- **Licence.** MIT lets anyone copy, rebuild and even sell Sensorline, including on Marketplace under another name. Open source plus paid works (customers pay for the convenience and updates), but MIT gives no protection against clones. Options:
  1. Keep MIT and rely on the name/brand and Marketplace review (clones must use a different UUID and name).
  2. Use GPL-3.0: clones must stay open source too, but resale is still allowed.
  3. Use a source-available licence (e.g. PolyForm Noncommercial, BSL): this blocks commercial clones, but it is no longer "open source" in the OSI sense.
  You may also want a short trademark note saying the name "Sensorline" and the icons are not covered by the code licence. This has not been changed; it is your call.
- **Profile switching on alert.** `switchToProfile` can only switch to profiles that the plugin bundles and declares under `Profiles` in the manifest. It cannot switch to a profile the user made. No profile is bundled, so this alert option is not offered. To add it, create a `.streamDeckProfile` in Stream Deck, add it to the plugin folder, and declare it in the manifest (with `DeviceType`). Users then get that profile installed with the plugin.
- **Sound.** `sounds/alert.wav` is a two-tone chime generated by `scripts/make-assets.ts` (no third-party audio; CC0). On Windows it plays through `System.Media.SoundPlayer` in a hidden PowerShell process.
- **Supported devices** listed in the description: all keypad devices, Stream Deck + (dial), Stream Deck Mobile and Virtual Stream Deck. Mobile and Virtual Stream Deck use the same keypad actions; check them before listing them.
